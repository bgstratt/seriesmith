seriesmith runs inside the ComfyUI you already have, on the models already in it. It's
also a page of its own, beside a ComfyUI or with none at all (Comfy's cloud). Whichever
way you run it, it's the same app, with the same projects and settings.

| Way | Good for |
|---|---|
| [1. Inside ComfyUI, from ComfyUI-Manager](#1-inside-comfyui-from-comfyui-manager) | Start here: one install, the editor in ComfyUI's sidebar |
| [2. On a page of its own](#2-on-a-page-of-its-own) | A browser tab of its own, the `seriesmith` command, a ComfyUI on another machine, or only Comfy's cloud |
| [3. A clone in custom_nodes](#3-a-clone-in-custom_nodes) | Following the newest changes on GitHub, or working on seriesmith |

Pick one way into a ComfyUI. The Manager install and a clone both take the folder
`custom_nodes/seriesmith`.

## 1. Inside ComfyUI, from ComfyUI-Manager

You need a ComfyUI that runs (developed against 0.38 and later) with ComfyUI-Manager.

1. Open **Manager → Custom Nodes Manager**, search for **seriesmith**, and install it,
   choosing the latest **nightly** as the version: the Comfy Registry hasn't approved a
   numbered release yet, and the nightly is the repo's `main`. Or, with comfy-cli once a
   release is approved: `comfy node install seriesmith`.
2. Restart ComfyUI.

Manager puts in the two Python packages seriesmith needs that ComfyUI doesn't already
have: Comfy's SDK (comfy-sdk, for Comfy Cloud and Router) and imageio-ffmpeg (an ffmpeg).
Nothing else is required. Updates come through Manager too.

seriesmith shows up in ComfyUI:
- **seriesmith Shots** and **seriesmith Refs** in the sidebar;
- **seriesmith Timeline** in the bottom panel.

It renders on that ComfyUI. To start, open **seriesmith Shots** and choose **Simple** at
the top of the sidebar, then **A clip**. Under **What happens?**, describe the shot, pick
who's in it and where, and press **Generate**.

## 2. On a page of its own

The same editor in a browser tab of its own (http://127.0.0.1:8190), and the `seriesmith`
command. It renders on the ComfyUI on this machine, one elsewhere, or Comfy's cloud. You
need git and Python 3.10 or later.

```
git clone https://github.com/bgstratt/seriesmith.git C:\code\seriesmith
```

Then double-click **`run_seriesmith.bat`** in it (Linux/macOS: `./run_seriesmith.sh`;
`run_seriesmith_ext.bat` opens it to your home network too).
- **The first time**, it sets itself up in the folder's `.venv`. That takes a minute or
  two.
- **Then** it opens the editor in your browser.

Installed from Manager already? `run_seriesmith.bat` is in that folder too
(`custom_nodes\seriesmith`): no clone needed. A Manager update replaces the folder, so
the next start sets up its `.venv` again.

With ComfyUI running on this machine, its **Features** window can add seriesmith's node
pack to that ComfyUI (**seriesmith's node pack**, under Tools). Without the pack, shots
still render there through ComfyUI's own nodes, and seriesmith says so once: what you
lose is latent continuity, kept latents, upscales and posts.

With no ComfyUI at all, set a Comfy API key in **Settings**: shots render on Comfy Cloud
and the hosted models through Comfy Router (Seedance, Kling, Veo, ...), billed to that
account ([Where shots render](/setup)).

## 3. A clone in custom_nodes

For following the newest changes on GitHub, or working on seriesmith: clone it into
ComfyUI's `custom_nodes`, as any node pack.

```
cd ComfyUI/custom_nodes
git clone https://github.com/bgstratt/seriesmith.git
```

Restart ComfyUI. That's all it needs to render on that ComfyUI.

Two packages Manager would have put in are optional here: Comfy's SDK, for Comfy Cloud
and Router, and imageio-ffmpeg, an ffmpeg for cutting and mastering. **Settings** gives
the command for the SDK once you set a Comfy API key, and **Features** downloads a full
ffmpeg. To put both in at once, with ComfyUI's own Python (the portable build's is
`python_embeded\python.exe`): `python -m pip install -r seriesmith/requirements.txt`.

`git pull` in that folder updates it (restart ComfyUI after). The same clone runs the page
of its own (2) too: `run_seriesmith.bat` is in it.

Keeping your clone somewhere else? Link its `comfy_nodes` folder into `custom_nodes`
instead (Windows: `mklink /J "<ComfyUI>\custom_nodes\seriesmith" "<clone>\comfy_nodes"` in
an ordinary Command Prompt; elsewhere `ln -s`): seriesmith finds the rest of itself
through the link.

## Which models it uses

When seriesmith starts and sees ComfyUI, it checks which models have all their files
installed. A series that doesn't name a model renders on the first one it finds:

| For | It looks for, in order |
|---|---|
| video | MiniMax H3 Ref2VA, LTX-2.5, LTX-2.3 ingredients, then the Wan 2.2 models (VACE, I2V, 5B) |
| pictures (characters, places, props) | Krea 2, FLUX.2 Klein, Z-Image Turbo, Qwen-Image 2.1, FLUX.3 Klein, MOSS-Image SFT, ... |

- **New projects:** new series and Simple-mode projects write the choice into their
  series config, so they keep rendering on it.
- **Your own pick:** choose another in **Settings** (Video model, Picture model).
- **Paid models:** hosted Comfy Router models (Seedance, Kling, Veo, ...) are never picked
  by themselves. Add a Comfy API key in Settings to use them (and Comfy Cloud).

**No models yet?** Every model picker has a **What's missing** button. It lists each file
the model needs, the ComfyUI folder it goes in, and the download link. With ComfyUI
running, `seriesmith targets` prints the same list from the command line. The smallest
complete set is the default pair: MiniMax H3 Ref2VA for video and Krea 2 for pictures
([INSTALL.md, The minimum set](/install#the-minimum-set)).

## What works now, and what's extra

With just this, you can do all of the following on the models you have:
- write and build episodes;
- render shots;
- make reference pictures;
- cut the episode;
- export it.

Some things need extra node packs, model files or software:
- MiniMax H3 at full quality (its sparse-attention node);
- generated voice samples;
- upscaling;
- post-processing (enhancement, motion blur);
- matching recorded dialogue;
- 360s of a place, and turning a character.

**Settings → Features…** lists them all. Tick what you want and press Install: it
downloads the model files and ffmpeg itself. A node pack it needs you install with
ComfyUI-Manager, and a Python package with the pip command it gives you to copy.
[Full setup](/full-setup) lists each one with what it needs.
